Detailed Description

Bit-field struct for the PETLINK singles word (type=1, deadtimeetc=2).

PETLINK 32-bit layout (little-endian): bits [18:0] = singles count (NiftyPET stores this pre-shifted left by 3) bits [28:19] = bucket index (0-based, up to NBUCKTS buckets) bits [30:29] = subtype/deadtimeetc = 0b10 (singles marker) bit [31] = type = 1 (non-event)
