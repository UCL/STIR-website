Detailed Description

Helpers for spacing analysis and axis inference from coordinate sets.

  • vector_utils::get_spacing_uniform computes successive spacings between sorted unique values and tests if they are uniform within a tolerance.
  • vector_utils::getLargestVector returns the largest of three coordinate sets and logs which axis is inferred as “axial”.

Compute spacings between sorted unique values and test uniformity.

Parameters
spacingOutput vector. Appends |x[i] - x[i-1]| for i=1..N-1, where x is the sorted version of unsorted_block_poss.
unsorted_block_possSet of unique positions (e.g., angles or translations).
epsilonTolerance for uniformity check (default 1e-4).
Returns
True if all spacings differ from the first spacing by <= epsilon, false otherwise.
  • If spacing ends up empty (e.g., input size < 2), returns true (trivially uniform).
