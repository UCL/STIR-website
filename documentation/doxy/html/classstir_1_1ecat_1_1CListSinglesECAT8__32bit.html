Detailed Description

A class for storing and using a singles bucket record from a listmode file from the ECAT 8_32bit scanner.

Singles records are emitted by the scanner approximately once per second per bucket. Each record encodes the singles count for one detector bucket over the preceding interval. These are used to estimate dead time and randoms.

The PETLINK singles word has type=1, deadtimeetc=0b10 (i.e. is_other() == true in CListDataAnyECAT8_32bit), so it falls through the existing time/event checks.
