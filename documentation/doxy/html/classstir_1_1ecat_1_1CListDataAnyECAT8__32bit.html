Detailed Description

A class for decoding a raw "other" word (neither time nor coincidence) from the ECAT 8_32bit listmode stream.

Used purely to classify the word type before dispatching to the appropriate handler. Reuses CListTimeDataECAT8_32bit's bit fields since type and deadtimeetc occupy the same bit positions across all non-event word subtypes.
