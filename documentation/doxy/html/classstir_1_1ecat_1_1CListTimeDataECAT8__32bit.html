Detailed Description

A class for decoding a raw events that is neither time or coincidence in a listmode file from the ECAT 8_32bit scanner Bit-field struct for the PETLINK time marker word (type=1, deadtimeetc=0).

PETLINK 32-bit layout (little-endian): bits [28:0] = time in milliseconds since scan start bits [30:29] = deadtimeetc (0 = pure time tick) bit [31] = type (1 = non-event)
