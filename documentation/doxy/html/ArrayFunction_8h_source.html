162/* local #define used for 2 purposes:
163 - in partial template specialisation that uses ArrayFunctionObject types
164 - in complete template specialisation for deficient compilers
165
166 This is done with a #define to keep code reasonably clean. Also, it allows
167 adjusting the type according to what you need.
168 Still, it's terribly ugly. Sorry.
169
170 Note that you shouldn't/cannot use this define outside of this include file
171 (and its .inl) partner.
172
173 Ideally, the code should be rewritten to work with any kind of (smart) ptr. TODO
174*/
175#if !defined(__GNUC__) && !defined(_MSC_VER)
176# define ActualFunctionObjectPtrIter VectorWithOffset<shared_ptr<ArrayFunctionObject<1, elemT>>>::const_iterator
177#else
178/*
179 Puzzlingly, although the code is actually called with iterators of the type above,
180 gcc 3.0 (and others?) gets confused and refuses to compile the
181 partial template specialisation (it says it's ambiguous).
182 VC also refuses to compile it.
183 A work-around is to use the following type
184*/
185# define ActualFunctionObjectPtrIter shared_ptr<ArrayFunctionObject<1, elemT>> const*
186#endif
