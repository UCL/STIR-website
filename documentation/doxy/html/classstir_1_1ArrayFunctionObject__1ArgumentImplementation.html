Detailed Description

template<int num_dimensions, typename elemT>
class stir::ArrayFunctionObject_1ArgumentImplementation< num_dimensions, elemT >

A convenience class for children of ArrayFunctionObject. It implements the 2 argument operator() in terms of the in-place version.

Sadly, we need to introduce another virtual function for this, as redefining an overloaded function in a derived class, hides all other overladed versions. So, we cannot simply leave the 1 arg operator() undefined here. Similarly, we could not only define the 1 arg operator() in a derived class.
