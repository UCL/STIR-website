Detailed Description

A class that gets the singles rates of the singles units ("buckets") from a JSON file.

The file needs the entries "interval_start" and "interval_end" (the times in seconds of each singles interval), "bucket_rates" (for each interval, an array with the singles rate of each singles unit), "num_axial_buckets", "num_transaxial_buckets", "num_rings" and "num_detectors_per_ring". Bucket i is at transaxial + num_transaxial_buckets * axial. This is what lm_to_projdata writes for list-mode data with singles records, for instance

{ "num_buckets": 224, "num_axial_buckets": 8, "num_transaxial_buckets": 28, "num_rings": 64,
"num_detectors_per_ring": 504, "interval_start": [0, 1.0], "interval_end": [1.0, 2.0],
"bucket_rates": [ [115378.4, 115102.2, ... ], [115280.1, 115015.7, ... ] ] }

get_singles_rate() averages the rates of the intervals that overlap the requested times, weighted by the overlap. The singles of a single interval are given by get_singles() with the start and end time of that interval.

In the parameter file, use

singles rates := SinglesRatesFromJSON
SinglesRatesFromJSON :=
filename := head2_f1_singles.json
End SinglesRatesFromJSON :=
