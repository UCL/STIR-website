Detailed Description

Class for an accumulated singles record in a listmode file.

Provides an interface to singles bucket data embedded in list-mode streams, following the pattern of ListTime and ListEvent.

Each record holds the number of singles accumulated by one singles unit (bucket) over some time interval. This is not a histogram in the sense of having multiple bins, and it does not describe individual singles events (which would need a different class).
